    Gemini API

    Gemini Flash / Flash-Lite と Gemma 4（26B・31B）だけを表示します。Pro・画像・音声・Thinking などは除きます。スクショ解析はこのモデルを使います。料金のWeb調査は Google 検索が必要なので、無料枠で検索できる Gemini 2.5 Flash（Lite を選んでいるときは 2.5 Flash-Lite）に固定します。Flash latest や Gemini 3 以降は、無料枠の検索上限が 0 です。
